# Submission Bundle

This folder contains all non-code submission assets:

- `SUBMISSION_CHECKLIST.md`: requirement-by-requirement completion matrix.
- `DEMO_SCRIPT.md`: 2-minute walkthrough script for live demo.
- `PRESENTATION_OUTLINE.md`: 5-slide content ready to paste into PPT/Canva.
- `API_SMOKE_TESTS.md`: curl commands for backend verification.
- `RESULTS.md`: current model metrics + scalability benchmark snapshot.

Technical artifacts generated by scripts:

- Model report PDF: `ml-service/models/model_report.pdf`
- Model comparison: `ml-service/models/model_comparison.json`
- Scalability benchmark: `backend/reports/scalability_report.json`
